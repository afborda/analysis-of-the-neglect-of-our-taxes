# Estudos e Anotações de Aprendizado

> Pasta para anotações pessoais, descobertas, resumos de artigos e aprendizados do projeto.

## Como usar esta pasta

Crie um arquivo `.md` por tema ou por sessão de estudo. Exemplos:

- `python-bigquery.md` — aprendizados sobre BigQuery com Python
- `modelagem-dados-municipios.md` — decisões de modelagem do nosso schema
- `analise-exploratoria-acre.md` — EDA do estado piloto
- `dbt-transformacoes.md` — padrões que usamos no dbt
